# FunJumps

Toggling the FunJumps mode for HNS servers, with a voting system

## Features
* **Teleport to saved position**
* **Toggling God mode** - To avoid taking damage
* **Toggling Collision** - To prevent players from colliding with one another

## Commands

* ``!fj`` - Opens the FunJumps menu
* ``!votefj`` - Initiates a vote to enable/disable funjumps
* ``!setfj`` - Toggling FunJumps without vote (Admin Command)

## Usage

### Server Requirements

* [SourceMod ^1.11](https://www.sourcemod.net/downloads.php?branch=stable)
* [CollisionHook](https://hlmod.net/resources/collisionhook.4141/) (resides in the repository)

### Installing
1. Contents of the core folder => /sourcemod
2. Compile the necessary modules => /plugins
3. Restart the server
4. Configure the file cfg/sourcemod/funjumps.cfg

### Needed for compilation
* [CollisionHook](https://hlmod.net/resources/collisionhook.4141/)
* [CS:GO Colors](https://hlmod.net/resources/inc-cs-go-colors.1009/)
